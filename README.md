# 🗑️ Greedy Trash

> Um jogo estilo Pac-Man com uma pegada ecológica e sustentável para conscientização ambiental.

---

## 📋 Sobre o Trabalho

O **Greedy Trash** foi desenvolvido como um projeto acadêmico (Atividade Prática Supervisionada - APS) com o objetivo de unir tecnologia, educação ambiental e entretenimento. 

Nesta versão temática do clássico arcade, o jogador assume o papel de uma **Lixeira** que precisa coletar resíduos espalhados pelo mapa, enquanto desvia dos **lixinhos** (os fantasmas do jogo tradicional). O projeto tem caráter lúdico, sem fins lucrativos, focado puramente na diversão e na reflexão sobre a importância do descarte correto e da reciclagem.

---

## 🎮 Como o Jogo Funciona?

- **O Jogador (Lixeira):** Move-se pelo cenário com o objetivo de limpar o ambiente coletando os itens disponíveis.
- **Os Inimigos (Lixinhos):** Perseguem a lixeira pelo labirinto. Ser pego por eles custa vidas no jogo.
- **Objetivo:** Limpar o mapa completamente, promovendo a ideia de um ambiente limpo e sustentável.

---

## 🚀 Tecnologias Utilizadas

- **Linguagem:** Java (Orientação a Objetos)
- **Interface Gráfica / Assets:** Sprites animados em formato `.gif` personalizados para o tema (Lixeira Frente, Costas, Lados e Tela Inicial).
- **Ambiente de Desenvolvimento:** VS Code / Eclipse / IntelliJ

## ⚙️ Como Executar o Projeto

- Certifique-se de ter o **Java Development Kit (JDK)** instalado em sua máquina.
- Clone ou baixe este repositório para o seu computador.
- Abra a pasta do projeto no VS Code (ou na sua IDE Java preferida).
- **Não se esqueça de mudar o caminho das imagens**
- Compile e execute a classe principal JanelaJogo.java.

---

## 🎯 Propósito Educacional

Este projeto demonstra a aplicação prática de conceitos de programação orientada a objetos (POO), manipulação de eventos, lógica de movimentação e tratamento de imagens/gráficos em Java, servindo como ferramenta de conscientização sobre a preservação do meio ambiente.
